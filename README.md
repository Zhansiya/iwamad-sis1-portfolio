GitHub Pages: https://zhansiya.github.io/iwamad-sis1-portfolio/

## About the Project

This is my personal portfolio website created for SIS Assignment 1.
It introduces me as an IT Management student and presents several projects I completed during the course.
The website is built with HTML, CSS, and vanilla JavaScript and supports both desktop and mobile screens.

## Design Decisions

1. I used a simple and minimal layout because I wanted the portfolio to be easy to read and navigate.

2. I chose beige, coral, and turquoise colors because they match the colors in my profile photo. This helps create a consistent and harmonious design.

3. For mobile screens, I changed the three-column project layout into a single column so that the project cards are easier to read on smaller screens.
